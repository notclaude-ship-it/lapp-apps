# LE SIGNAL — mini expérience d'horreur

Une mini expérience web en français avec terminal d'ambiance et un bouton de surprise visuelle.

## Lancer
1. Dézippe `phantom_terminal.zip`.
2. Ouvre `index.html` dans un navigateur.
3. Clique sur **TENTER LE SIGNAL (10 %)** : chaque clic a exactement une chance sur dix de déclencher le jumpscare visuel.

Le jumpscare est une illustration stylisée en CSS, sans son soudain. Tu peux le fermer avec la croix ou la touche Échap. Aucun accès au micro, à la caméra ou aux fichiers personnels.

## À propos du SDK
L'intégration de `lapp-sdk` n'a pas pu être vérifiée ici : ce prototype est autonome.
